# Oil Spill Detection using Deep Learning

This project leverages deep learning techniques to detect oil spills in satellite imagery using a convolutional neural network (CNN) model. The notebook contains data loading, preprocessing, model training, and evaluation steps.

## Features

- Image preprocessing and augmentation
- CNN model architecture built with Keras/TensorFlow
- Model training and evaluation metrics
- Visualization of predictions
